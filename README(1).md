# 🖥️ Cool Terminal Apps on Linux

A curated list of awesome terminal applications for Linux — tools that make the command line more powerful, beautiful, and fun.

---

## 📁 File Management

| App | Description | Install |
|-----|-------------|---------|
| [ranger](https://github.com/ranger/ranger) | Vi-inspired file manager with previews | `sudo apt install ranger` |
| [nnn](https://github.com/jarun/nnn) | Blazing fast, lightweight file manager | `sudo apt install nnn` |
| [lf](https://github.com/gokcehan/lf) | Terminal file manager inspired by ranger | `go install github.com/gokcehan/lf@latest` |
| [broot](https://github.com/Canop/broot) | A new way to see and navigate directory trees | `cargo install broot` |
| [mc](https://midnight-commander.org/) | Midnight Commander — classic two-panel file manager | `sudo apt install mc` |
